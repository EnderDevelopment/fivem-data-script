# FiveM Data Script

A versatile FiveM script for handling player data and events.

## Features

- Handles player data through database interactions
- Provides client-server communication for events

## Requirements

- FiveM server with ESX Legacy framework
- MySQL database

## Installation

1. Download the script files
2. Place them in your FiveM server's resources folder
3. Add `start fivemscript` to your server.cfg

## Usage

### Client-side

- Press the E key to trigger a server event
- Receive notifications from server events

### Server-side

- Handles database queries for player data
- Manages client-server event communication

## Configuration

Edit the `config.lua` file to customize database settings and script behavior.
